# 虚空电台 1680 AM 电子辅助工具

这是一个纯前端、离线可用的《虚空电台（VOID 1680 AM）》游戏辅助工具。它负责抽牌、掷骰、规则查表、歌单记录、跨局人物卡和广播历史；不会播放音乐，也不会替玩家生成叙事内容。

## 如何运行

直接双击项目根目录中的 `index.html`，使用桌面版 Chrome 或 Edge 打开即可。核心功能不需要网络，也不需要安装依赖。

如果浏览器限制本地文件，可在项目目录运行任意静态文件服务器，例如：

```text
python -m http.server 8000
```

随后访问 `http://localhost:8000`。静态服务器只是备选方式，不是运行本项目的必要条件。

## 数据保存在哪里

所有数据保存在当前浏览器的 `localStorage` 中：

- `void1680_settings`：扩展模式与显示设置
- `void1680_activeBroadcast`：未完成的当前广播
- `void1680_callers`：16 张人物卡的跨局状态与已结束故事
- `void1680_history`：已完成广播的只读历史

更换浏览器、使用隐私模式或清理站点数据后，这些记录不会自动迁移。

在“广播历史”中打开某一场广播后，可以单独清除该场记录。清除时只会同步移除这场广播产生的来电者备注，不会删除其他广播中的同一人物记录。

歌曲相关来电会按标准牌面数值自动关联当前版块的歌曲牌：A=1、J=11、Q=12、K=13，并选择数值距离最近的数字牌。

## 如何清空浏览器存档

打开工具，进入“设置与关于”，点击“清空所有浏览器存档”。该操作会删除当前广播、人物卡、广播历史和设置，且无法撤销。

也可以在浏览器开发者工具的 Application / Storage / Local Storage 中删除上述四个键。

## 部署到 GitHub Pages

1. 将整个项目提交到 GitHub 仓库。
2. 在仓库 Settings → Pages 中，将发布来源选择为分支。
3. 选择包含 `index.html` 的分支和根目录 `/`。
4. 保存后等待 GitHub Pages 给出站点地址。

项目使用相对路径，不需要构建步骤。GitHub Pages 上的数据仍然只保存在每位访问者自己的浏览器中。

## 项目目录

```text
.
├── index.html          页面外壳与脚本入口
├── css/
│   └── style.css       电台控制台风格、响应式与可访问性样式
├── js/
│   ├── rules.js        中文规则提示与查表数据
│   ├── storage.js      localStorage 读写
│   ├── game.js         洗牌、状态转换、人物故事生命周期
│   ├── ui.js           各界面渲染
│   └── app.js          事件绑定与应用协调
└── tests/
    ├── game.test.js    核心规则与完整广播流程测试
    └── storage.test.js localStorage 保存与恢复测试
```

## 支持范围

- 桌面 Chrome / Edge 优先，最低可用宽度 1024 px
- 移动端提供基本可用布局
- 不包含音乐服务 API、登录、云同步、多人游戏、录音或 AI 生成功能
